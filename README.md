# AI-Coding: Kode som en pirat 🏴‍☠️

Kursusmateriale til et 7-ugers AI-coding-forløb for Coding Pirates (12-17 år), hvor børnene bygger et nyt browserspil hver gang — med stigende sværhedsgrad — og lærer at arbejde design-drevet med en levende spec, mens en AI (Mistral Vibe i VS Code) skriver koden.

**Læs [`disposition.md`](disposition.md) først** — den samlede plan: læringsmål, piratkodekset, rytmen for hver gang, og de syv kursusgange i detaljer.

## Struktur

| Mappe | Indhold |
|---|---|
| [`disposition.md`](disposition.md) | Den fulde kursusdisposition |
| [`materialer/`](materialer) | `spec_skabelon.md` (designdokument-skabelonen) og `spil_canvas.pdf` (printklart papir-canvas) |
| [`starter_template/`](starter_template) | De filer, hvert spilprojekt starter fra: `index.html`, `style.css`, `script.js`, `spec.md`, `AGENTS.md` |
| `gang-1/` … `gang-7/` | Materiale specifikt til hver kursusgang (slides m.m.) |

## De syv kursusgange

1. **Snake / Tetris** — setup + første spil med tema
2. **Memory** — kort, match og fuld spec-rutine
3. **Sokoban** — baner, regler og 2D-grids
4. **Skydespil** — fjender, spawning og gameloop
5. **Platformer** — gravity, collision og must/nice-disciplin
6. **Eget projekt** — fra spec til spilbart
7. **Demo-dag** — færdiggørelse + fremvisning

Gang 2-7's mapper er oprettet, men tomme, indtil materialet til hver gang er klar.
