# Materialer

Genbrugeligt materiale på tværs af alle 7 kursusgange.

- **`spec_skabelon.md`** — den kanoniske skabelon for spillets designdokument (spec.md). Bruges også som reference i `../starter_template/spec.md`.
- **`spil_canvas.pdf`** — printklart A4-canvas ("søkortet") til at udfylde spec'en med blyant, før man åbner VS Code.
