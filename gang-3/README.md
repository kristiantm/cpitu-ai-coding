# Starter-skabelon 🏴‍☠️

Kopiér denne mappe, hver gang du starter et nyt spil — den indeholder de fem filer, alle spil bygger på:

| Fil | Formål |
|---|---|
| `index.html` | Skelettet — det, der ER på siden |
| `style.css` | Udseendet — farver og stil |
| `script.js` | Hjernen — reglerne og logikken |
| `spec.md` | Dit søkort/designdokument — udfyld det, før du koder! |
| `AGENTS.md` | Rammerne AI-hjælperen (Vibe) arbejder inden for — læses automatisk |

## Sådan bruger du den

1. Kopiér mappen og navngiv den efter dit spil, fx `spil-1-snake/`.
2. Udfyld `spec.md` — brug papir-canvas'et (`materialer/spil_canvas.pdf`) først.
3. Åbn mappen i VS Code og bed Vibe om at læse `spec.md` og bygge det første punkt på must-listen.
4. Test spillet efter hver ændring, og opdater `spec.md`, når spillet ændrer sig.
